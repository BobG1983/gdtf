# Agent memory index

Links every **real** memory file. Ephemeral is never listed.

`/dream` promotes verified facts from `*/ephemeral/` into `*/real/` and rewrites this file.
A promoted memory has been re-checked against the tree — if one contradicts the code, the code
wins and the memory is wrong.
